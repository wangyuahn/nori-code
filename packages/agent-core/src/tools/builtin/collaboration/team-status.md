Read the current Agent's direct persistent Team Agent members.

The result shows each member's identity, current observable `idle`/`running` status, assigned task, latest explicit TeamDM report status (`unreported`, `completed`, `blocked`, or `needs_decision`), report summary, and whether the parent has received that report. Ordinary TeamDM messages are not classified as reports. A running member is still working: do not take over or repeat its task; wait for TeamDM or query this tool again. It does not include temporary SubAgents.
