Read your own department: the peers hired alongside you, and the persistent Team Agent members you hired yourself.

`colleagues` lists your peers — same parent as you, reachable directly by agent id with `TeamChat` or `TeamDM` — with each one's role, observable `idle`/`running` status, assigned task, and whether it has reported to your shared parent yet. Use it to see who owns which part before you touch a file near their scope, and to name the peer a handoff belongs to. `parent_agent_id` is the agent that hired you.

`members` lists the members you hired: identity, `idle`/`running` status, assigned task, latest explicit TeamDM report status (`unreported`, `completed`, `blocked`, or `needs_decision`), report summary, and whether you have received that report. Ordinary TeamDM messages are not classified as reports.

A `running` agent is still working: let it finish rather than repeating or taking over its task, and read its `TeamDM` or query this tool again.
