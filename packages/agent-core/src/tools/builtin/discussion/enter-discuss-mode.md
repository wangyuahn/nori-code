Enter a read-only Discuss stage for team conversation.

Discuss is a team meeting:
- Write, Edit, Bash, and SubAgent are blocked.
- Create durable partners with TeamCreate when needed.
- Run rounds with TeamDecide. Members publish only with TeamSpeak; not calling it records abstention.
- TeamAssign leaves Discuss and enters Code.
- After execution, TeamDecide action=vote does not require Discuss.

Do not write a session file or present approval options. The UI Discuss/Code toggle can also leave or re-enter this stage.
